# 数学教材抽取规范

## 来源与教材身份

以依法取得的教材 PDF 为内容依据，记录学段、出版社、年级、册次、版次、课程标准修订标记、SmartEdu 资源 ID 和 PDF SHA-256。不同版次分别维护；相同书名、出版社或章节标题不构成同版证据。

在 SmartEdu 教材与课程教学目录中匹配同版教材，逐项对照单元、课题及层级。匹配依据与差异记录于 `outline_alignment.json`。无法确认的信息保留为明确的元数据状态，不使用其他版本替代。

## 知识点组织

- 章节与课题层级以同版网站实际目录和教材位置为依据。小学按实际课题组织记录，同一章内同一课题对应一条知识点，不同课题不合并，不以父章名代替末级课题。初高中在目录层级内按教材明确的概念、性质、定理、方法、公式及条件细分知识点；名称准确标识数学内容，不为每道例题另造知识点。
- 阅读、探究、综合实践等栏目的有效补充数学内容，按教材出现位置就近归入前一小节，不因主题相近回挂前面的其他小节或章节。来源记录保留实际栏目、原位置和编辑分组依据；章引言保留章级位置，不归入尚未出现的小节。
- 正文已完整讲解的内容不重复收录整理复习、总复习等位置的相同表述，也不追加重复页码。确实新增的概念、明示条件或方法可以保留，重复片段及其来源留存于审计记录。
- 游戏、练习、整理复习、软件操作、科普历史或报告任务不因栏目标题单独建立知识点。涉及数学概念的原文片段映射到实际课题。
- 历史人物、年代、发展经过和评价性叙述不单列知识点。混合栏目按片段识别数学内容，保留必要的定义、公式、条件、方法与已讲解原例；不因公式或方法以人名命名而排除，也不删除理解数学原例所必需的历史情境。
- 无法确认教材身份或目录归属的内容保留于来源记录，不以空名称记录进入主表；平台未单列的补充栏目按上述就近归属规则处理。
- 普通增补或格式转换中，一一对应记录保留 ID。整册顺序修订或明确要求重新编号时，先确定最终记录顺序，再按册连续重编 ID；不得仅按旧 ID 排序。新增、拆分、合并、改名、归属变更或移出主表均记录动作、原因、完整前后记录、旧新 ID、教材身份、源页、版本和恢复位置，不复用已移出记录的 ID 指代不同内容。

## 内容转录

正文仅收录教材原文、原有公式和明示条件；例题字段仅收录已讲解原例与原解。保留术语、数字、符号、语序和条件，不补写定义、推导、练习答案或外部常识。

`detail` 保留完整的核心讲解。教材以情境、图示、算式或具体例题介绍知识而没有独立定义时，将必要题干、算式、原解及图示一并保留在 `detail`，不只摘取符号名称或孤立题干。`example` 仅收录可以自然分离的补充原例，不把核心讲解拆走；没有补充原例时留空。

同一知识点中仅替换数字或情境的同类型原例保留首次完整讲解。不同方法、条件、题型及用于必要对比的子题不机械去重。未解填空保留原有空格，不补答案。图示情境中的小图无法以文字转录时，可按明确授权使用统一图形占位，并保留原图引用。相同文字只保留一次，其后依次附上对应图片。

PDF 文字层和 OCR 是转录候选，不是核验结果。逐页检查负号、分式、指数、根号、向量、括号、单位、表格及跨页段落。复杂二维表达、竖式或图示不能无损转写时，关联原图和源页，不压缩为有歧义的线性公式。

## 字段与页码

主 CSV 使用 UTF-8 BOM，字段顺序固定为：

```text
knowledge_point_id,chapter,subchapter,section,knowledge_point,detail,example,pdf_page
```

`knowledge_point_id`、`knowledge_point` 和 `detail` 非空，`example` 可为空。无更细目录层级时可使用同一实际目录名称，不增加自拟层级。

`pdf_page` 指 PDF 物理页序，不混用教材印刷页码。连续页使用 `P20-P21`，不连续页使用分号列出，例如 `P20;P24-P25`。页码与来源片段对应关系保存在 `source_records.jsonl` 和页码映射中。

## 图片

源数据采用 `![page-NNN](images/<book>/page-NNN.png)`，图片放在对应完整段落后。Markdown 阅读视图根据文件位置调整相对路径。图片说明采用实际文件名，整页与裁剪图的类型、位置及来源记录在元数据中。

同一记录的同一字段中，相同整页图片路径仅保留一次，置于该页相关完整讲解之后；文字分段不构成重复插入同一整页图片的理由。不同裁剪图须具有不同路径和裁剪位置记录，按各自对应内容保留。`detail` 与 `example` 分别按各自内容关联必要图源，不以另一字段的图片代替。

文件存在检查不等同图文对应核验。核对图片中包含所引用的图示，保留必要上下文，不以自行绘制或解释的内容替代原图。

## 工具与校验

PDF 文字层准备：

```sh
python skills/smartedu-math/scripts/prepare_pdf.py textbook.pdf --output-dir work/book
```

输出 `pages.jsonl` 与 `source_report.json`，供视觉核对和转录定位。附带的 `validate_results.py` 使用七字段章节中间格式，不直接校验八字段主表。当前 CSV、Markdown 与资源文件使用：

```sh
python scripts/validate_package.py
```

校验分为字段结构、ID 与来源映射、原文忠实性、公式与图示、目录覆盖及同版名称对齐。各项分别记录；程序结构检查不替代内容核对。

维护教材身份、目录对齐、来源片段、图片位置、旧新 ID 映射和变更记录。新增抽取结果与既有数据分开保存，内容合并和版本替换应具有可追溯的差异记录。来源标识、操作备注和审计状态不混入教材正文。
