## 内容处理

`detail`保留核心讲解与必要的情境、推导、算式和核心原例原解；5个`example`字段只放可自然分离的补充已讲解原例。电势差与电场强度关系的平行板原例及随后动能解释完整留在`detail`。电子偏转的推导例、仪器读数原例、实验参考方法及充电宝研究数据也留在`detail`。

实验保留教材给定器材、连接方式、步骤、现象和明示结论。静电感应、静电屏蔽等实验中的原有观察问题没有补结果；感应电流实验的原表空栏保留为空。传感器图像的未解面积估算及另行设计任务未补答案。课题研究四表原数据、U-I图像、操作及结论完整保留，结论仍限定于教材所测充电宝。

历史栏目按片段取舍，保留库仑扭秤原理与脚注限制、分子电流假说、地磁偏角和射电望远镜等有效内容；纯历史评价、项目指标、未解练习及未开展的参考选题不另录入。不同条件、方法及必要对比保留。

全部143页通过渲染图逐页检查，并对23个公式、单位、仪器读数与数据表密集页单页放大复核。文字层只作为候选，最终正文锁定在`patches.json`。跨页句子先合并为完整讲解，随后附来源整页图。图中细节以原图为依据，不用自行绘图替代。

`source_records.jsonl`的`regions`是候选定位选区，不应理解为最终转录逐字的精确裁剪边界；最终审阅可追溯至记录所列完整源页图。补充原例另有`example_pages`。`change_log.jsonl`保留候选与最终全文，便于恢复和复查。
